Design system v0.2

Cromoswap now covers album completion, duplicate counters, import, and live scanner targeting.

This update translates the approved CX specs into reusable visual decisions: batch album controls, a reps counter grid, import/restore states, a back-home shell pattern, and an aspect-ratio scanner frame that can turn green when targeted.

Approved CX stories

Flow states represented as design surfaces

These states map to the June 5 CX specs: start/resume/import, live scan targeting, My Album batch fill, My Reps grid counters, collection review, and export.

Story 1

Create, resume, or import

Returning collectors should see resume first, while import is available from the start screen for text lists and JSON backups.

  • Resume card keeps album and scan counts visible.
  • Import sits next to session recovery, not inside a scan tab.
  • New sessions remain deliberate and simple.

Visual tokens

Friendly scanner utility, not generic dashboard

Green remains the scan and ownership anchor. Blue is now explicitly import and information. Amber is review, duplicate spares, and ambiguous text import.

Color schemes

Three implementable palettes with the same semantics

The token files expose these as CSS custom properties and JSON values for the web service. Table day is the default; the other schemes are optional surfaces for low light and high-contrast QA/export contexts.

Table day

Default light UI for one-handed sorting around a table.

data-cromoswap-scheme="table-day"

Stadium night

Dark scanner surface for dim rooms without changing state meanings.

data-cromoswap-scheme="stadium-night"

Print proof

Higher contrast light UI for screenshots, classrooms, and exported docs.

data-cromoswap-scheme="print-proof"
